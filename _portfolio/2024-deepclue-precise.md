## Overview

DeepClue-Precise is MRI and CT analysis software designed to support collateral assessment in stroke imaging. The project translated research prototypes into clinically deployable software with defined requirements, verification activities, and regulatory documentation.

![DeepClue logo](/images/timeline/deepclue_logo.png)

## My Contributions

- Led clinical-requirement analysis, system architecture, implementation planning, verification, documentation, and team operations.
- Developed the MRI application and processing pipeline, including DICOM preprocessing, image analysis, GUI development, output generation, and testing.
- Designed a reusable application framework adopted by the CT product while collaborating with the developer responsible for its CT-specific core processing pipeline.
- Planned and executed software verification and validation and supported MFDS Class I medical-device registration activities.
- Supported hospital prototype deployment and translated clinical feedback into software requirements and validation criteria.

## Focus

This work connected medical-image research with production software engineering, quality management, regulatory requirements, and real clinical workflows.
